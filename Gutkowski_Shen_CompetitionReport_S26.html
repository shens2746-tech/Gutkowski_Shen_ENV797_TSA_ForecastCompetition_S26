1. Introduction

The objective of this project is to forecast daily electrical load using historical load data and meteorological variables. Multiple time series models were evaluated, including seasonal decomposition methods, ARIMA-based models, neural networks, and models incorporating exogenous weather variables. Model performance was assessed using RMSE and Kaggle competition scores. Top performing models included solo and combinations of TBATS and Neural Network models.

### Load and process raw data

load_raw <- read_xlsx("./Data/Raw/load.xlsx")
humid_raw <- read_xlsx("./Data/Raw/relative_humidity.xlsx")
temp_raw <- read_xlsx("./Data/Raw/temperature.xlsx")

# Process load data
load_proc <- load_raw %>% 
  mutate(daily_ave = rowMeans(load_raw[,3:26], na.rm = TRUE)) %>% 
  select(date, daily_ave)

# Process humidity
humid_proc <- humid_raw %>% 
  group_by(date) %>% 
  summarise(across(3:26, ~ mean(.x, na.rm = TRUE)))

# Process temperature
temp_proc <- temp_raw %>% 
  group_by(date) %>% 
  summarise(across(3:26, ~ mean(.x, na.rm = TRUE)))

# daily mean temperature
temp_daily <- temp_proc %>% 
  mutate(daily_temp = rowMeans(across(-date), na.rm = TRUE)) %>% 
  select(date, daily_temp)

n_for <- 31
full_len <- nrow(load_proc)

# Align temperature with load training
train_temp <- temp_daily$daily_temp[1:(full_len - n_for)]
test_temp  <- temp_daily$daily_temp[(full_len - n_for + 1):full_len]

# Create time series
full_load_ts <- msts(load_proc$daily_ave, 
                     seasonal.periods = c(7, 365.25), 
                     start=c(2005,1,1))


train_data <- load_proc[1:(full_len - n_for), ]
test_data  <- load_proc[(full_len - n_for + 1):full_len, ]

train_load_ts <- msts(train_data$daily_ave,
                      seasonal.periods = c(7, 365.25),
                      start = c(2005,1,1))

test_load_ts <- msts(test_data$daily_ave,
                     seasonal.periods = c(7, 365.25),
                     start = end(train_load_ts) + c(0,1))


# Training Fourier terms
fourier_train <- fourier(train_load_ts, K = c(2,12))

# Test Fourier terms
fourier_test <- fourier(train_load_ts, K = c(2,12), h = n_for)



# Fourier terms + temperature
train_xreg <- cbind(fourier_train, temp = train_temp)
test_xreg  <- cbind(fourier_test,  temp = test_temp)

6. Results and Discussion

The results indicate that seasonal structure is the dominant driver of electrical load. In the Kaggle competition, the 90/10 weighted TBATS–Neural Network model outperformed all other models, showing that combining models can improve forecasting performance.

While the neural network model with Fourier terms and temperature performed best based on RMSE, it did not translate to strong Kaggle performance. This suggests that incorporating weather variables does not necessarily improve forecasts compared to models that more effectively capture complex seasonal patterns, such as the TBATS+NN combinations.
